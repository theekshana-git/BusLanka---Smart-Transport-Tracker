**BusLanka** is a decentralized, real-time public transit tracking mobile application. It utilizes live GPS telemetry and dynamic ETA calculations to bridge the gap between commuters and transit networks, offering a scalable solution for modernizing transport infrastructure.

## 🚀 Key Features
* **Real-Time GPS Telemetry:** Live spatial tracking of transit vehicles using Firebase Realtime Database.
* **Dynamic ETA Calculations:** Predictive arrival time algorithms based on live location data.
* **Decentralized Architecture:** Operates efficiently across distributed driver and commuter nodes.
* **Cross-Platform UI:** Built with Flutter for native performance on both iOS and Android.

## 🛠️ Technical Stack
* **Framework:** Flutter, Dart
* **Backend Services:** Firebase (Firestore & Realtime Database)
* **Architecture:** State Management, Mobile-First Design, Real-time Data Sync

## 💻 Local Development Setup

**1. Clone the repository:**
`git clone https://github.com/theekshana-git/BusLanka---Smart-Transport-Tracker.git`  
`cd BusLanka---Smart-Transport-Tracker`

**2. Install dependencies:**
`flutter pub get`

**3. Run the application:**
`flutter run`
*(Requires a connected emulator or physical device)*
